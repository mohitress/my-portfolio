# 🌟 My Developer Portfolio & Git Playground

Welcome to my personal developer portfolio! This project was built to practice version control using **Git** and learn how to host and manage code on **GitHub**.

---

## 🎯 Purpose of this Project
- Learn how Git tracks changes locally on my computer.
- Practice fundamental Git commands: `status`, `add`, `commit`, `branch`, and `merge`.
- Learn how to push code to a remote repository on **GitHub**.
- Publish this portfolio live on the web for free using **GitHub Pages**.

---

- **HTML5**: Semantic document structure.
- **CSS3**: Modern styling, flexbox/grid, and Dark/Light theme switching.

- **Git**: Distributed version control.

## 📚 Git Workflow Reference
Here is a quick cheat sheet for everyday Git usage:

| Command | What it does |
| :--- | :--- |
| `git status` | Checks what files were modified or staged |
| `git add .` | Stages all changes for the next commit |
| `git commit -m "Message"` | Saves a snapshot of your staged changes |
| `git log --oneline` | Views commit history in a concise format |
| `git checkout -b feature-name` | Creates and switches to a new branch |
| `git push -u origin main` | Pushes your local commits to GitHub |
